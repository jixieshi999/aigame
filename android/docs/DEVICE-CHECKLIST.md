## 🛠️ 常用排查与诊断命令

### 1. 实时查看 Node.js 服务端标准日志
```powershell
adb logcat -s JiMaoNodeServer
```
*正常输出示例*：
```text
I JiMaoNodeServer: 几猫局域网 A/B/C/D 阶段 · 构建 9e55b5200b088ada · 协议 3
I JiMaoNodeServer: Node 运行时：v18.20.4
I JiMaoNodeServer: 本机：http://localhost:8787/
I JiMaoNodeServer: 局域网：http://192.168.2.35:8787/
```

### 2. 检查监听端口是否开启
```powershell
adb shell "cat /proc/net/tcp"
```
查找本地地址十六进制 `2253`（8787 的十六进制为 `0x2253`），状态为 `0A`（LISTEN）。

### 3. 从电脑终端直接测试 HTTP 响应
若手机连接电脑并通过 USB 调试，可映射端口快速测试：
```powershell
adb forward tcp:8787 tcp:8787
curl -I http://127.0.0.1:8787/
```
预期返回：`HTTP/1.1 200 OK`

## ⚠️ 常见问题与对策

1. **客机扫码后提示“网页无法访问”或打不开：**
   - **检查 Wi-Fi 是否隔离**：部分公共 Wi-Fi 或企业级路由器开启了“AP 隔离（Client Isolation）”，阻止手机间互相通信。请改用家用普通路由器，或直接开启本主机的【免路由器临时热点】。
   - **检查 IP 地址**：若手机连接了多个网络（如以太网 + Wi-Fi），点击界面上的【切换接口】选择正确的局域网网卡。

2. **息屏一段时间后客机断线：**
   - 部分激进省电系统（如厂商专属“神隐模式”、“智能省电”）会强行切断后台网络。
   - 请在设置中确保“几猫主机”的“允许后台活动”、“允许自启动”已打开，并在应用内点击【加入电池白名单】。

3. **自建临时热点提示 `ERROR_GENERIC` 或 `ERROR_INCOMPATIBLE_MODE`：**
   - 模拟器由于缺乏实体无线网卡，不支持自建热点，属于正常现象。
   - 某些真机芯片若正在连接特定 Wi-Fi，可能不支持同时发射热点。请在手机设置中直接开启系统【个人热点】，几猫主机会自动捕获热点网段。
