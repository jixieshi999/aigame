# D 合作流程交付与验证

日期：2026-11-11。范围为 D1–D5，基于 C 的房主权威共享战斗。原 HTML 只读，运行时零 npm 依赖；E 的玩家互伤、队伍比分和胜负未实现，`pvp` 保持 C 的分队/改色/共享初始 NPC 行为。

## 实现

- D1：协议 v3；world 携带合作 flow 与玩家 deaths/respawnIn/invuln；服务器校验 options、身份、seq、限流及大小。出生池/选点与生命周期纯函数位于 flow-shared.js，合作控制器位于 flow-coop.js。
- D2：靠近中继按住 E，客户端200ms心跳，房主400ms超时。房主按存活、水平2.2m、垂直2.5m及朝向余弦0.45校验；多人速度上限2.5倍；按中继ID幂等提交。
- D3：初始巡逻、三波与追击由房主统一生成，候选点评估所有存活队员。倍率 min(3,1+0.5*(N-1))，飞鸥10/猎犬8/总计18上限。队列首刷1.6秒、间隔0.85秒、每步最多出队1个，满员延后1秒，失败最多6次。
- D4：权威死亡计数、默认10秒倒计时、点击/Enter复活、3秒保护。复活只调用已保存的 player.reset 和 weapon.reset，再通过 paused→resume 恢复原输入；不调用 game.start。全灭（含待复活者）立即失败。
- D5：所有存活队员水平距离<2.5m、垂直差<3.5m且保持1.5秒成功；离圈清零，死人不阻塞，至少一人存活。结算含全队统计、原评级与个人表。终局停止AI/伤害/开火，仍约10Hz发布最终完整快照，供晚加入缓存。房主重开新 round 清空全部流程。

昵称与网络字符串只使用 textContent/Canvas；独立死亡和结算层不使用 innerHTML 或向原 hud.feed 传昵称。出现覆盖层时收起大厅，避免遮挡。PvP 专用协议事件留给 E，不提前允许玩家伤害事件。

## 夹具与自然输入的区别

合作综合测试通过原公开 player.pos/yaw/enabled 固定中继和撤离位置，避免把长距离寻路操作混入协议验收。并发切断使用实际 WebSocket 报文、200ms心跳及房主校验；重开后的 E 键检查使用真实 Playwright 键盘输入和产品客户端心跳。综合测试包装公开 enemies.spawn 追加 passive:true，以隔离随机受击，但生成、队列、对象池、enemyId和同步均运行真实模块。

死亡通过公开 player.damage 入口触发，并经房主处理；没有直接改权威actor生命。个人复活实际点击产品按钮，鼠标移动及D键由Playwright发送；输入验证不固定相机、不使用 __setShot、不伪造输入状态。controls用一个真实页面和一个持续发位姿的原始WS成员排除全灭，并清除敌人，验证默认10秒流程；合作综合另有两页面死亡/复活和全灭。

综合测试开始的个人复活仍使用默认10秒；其后的重开夹具通过 roundReset.options 设置respawnSec=1，缩短全灭/重开场景等待。其他页面冷启动期间，已有页面只将GPU出帧降到2Hz并随后恢复，网络/房主模拟继续；这不是三页面性能测试。C回归使用公开生成/瞄准/临时遮挡夹具与真实鼠标开火，详见C记录。A/B独立表现脚本本轮未另跑。

## 设计调整与接口依赖

1. quay候选搜索Z范围扩到[-28,26]，以在固定gate池对所有点的遮挡/40m条件下找到24个点；最终选定点Z在[-27.35,-5.25]。实际两队最近47.827m、576对无视线。D只使用coop池，两个team池为E提供接口，未把E规则提前应用到PvP。
2. 出生点网格间距1.3m（高于要求1.2），候选点及周围±0.6m九点均做nav校验；这是导航采样校验，未把它描述为精确几何墙距测量。
3. 回退遵循原HTML中的 `t=max(0,t-dt*1.6)`，即每秒回退1.6单位进度；设计“1.6倍”措辞可能被理解为切断速度的1.6倍，这里按核实的原程序行为保持。
4. 本次不加载空的flow-pvp.js；两路由约束不变，/net.js只在内存拼接combat、flow-shared、flow-coop、net四个模块。world.flow对保持C行为的PvP可省略，旧C玩家夹具的新增字段默认0/null/false；线上D合作始终发送完整字段。
5. 结算由独立DOM实现；保留终局world发送而不把传输状态设为ended，防止晚加入只拿到旧状态。host离线的ended政策仍由服务器控制。
6. 依赖已锁定HTML公开的player.reset、weapon.reset、game.resume/state/menus、hud.setRelays/setObjective/setMarkers/setPrompt/radio/warn，以及level/physics/enemies接口。原dead状态的单机菜单更新被联机层拦截；复活显式恢复enabled、ads、后处理色彩，并重放合作HUD。原私有控制器不参与联机任务推进。
