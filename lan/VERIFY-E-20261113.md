# E 基础 PvP 与移动端修复验证

日期：2026-11-13  
范围：PvP 玩家命中/扣血、敌人数量、触屏继电器入口、横屏提示、原创仓库地图。

## 已完成

- `flow-pvp.js` 提供与浏览器无关的命中部位、伤害、友伤、比分和时间结算规则。
- 房主在 `combat.js` 对静态遮挡后的玩家胶囊做最近命中判定，身体伤害 22，头部伤害 38.5；命中通过 `shotResult.victimId` 和 `hurt` 事件同步，致死通过 `playerKill` 和队伍比分同步。
- PvP 出生使用确定性双队出生池，出生保护 3 秒；合作和 PvP 都可用个人复活入口。
- 合作初始巡逻由 2 飞鸥/1 猎犬增加到 3 飞鸥/2 猎犬，波次数量仍受飞鸥10、猎犬8、总存活18的原对象池上限约束。
- 手机端新增独立“交互”触屏按钮；按住按钮通过联机层桥接到中继心跳，不改写原 HTML 的触控实现。连接或首次触摸时尝试 `screen.orientation.lock('landscape')`，拒绝时显示横屏提示。
- `lanMap=warehouse` 增加原创程序化仓库几何和碰撞盒，新增盒子计入静态地图摘要；没有复制第三方 CS 地图文件。

## 未实测与边界

- 没有真实 Android/iOS 设备、两台手机 Wi-Fi、系统自动旋转、浏览器横屏锁定权限或触屏长按时长的实测；当前移动行为依据 Playwright/代码路径和浏览器 API 失败回退提示。
- 没有20个真实浏览器的帧率/带宽、弱网、延迟回溯和完整反作弊验收。
- 仓库地图是原创程序化场景，尚未做美术资产、手机性能和长时碰撞稳定性验收。

## 约束核对

- 服务器仍只提供 `/` 和 `/net.js`，`/net.js` 在内存拼接脚本；运行时零 npm 依赖。
- 所有昵称、状态和玩家击杀提示沿用 `textContent`/Canvas；没有将网络字符串写入 `innerHTML`。
- 修改和新增文件均位于 `lan/`；原 HTML 没有复制、生成或写回。
